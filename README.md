# 3Ds-Sc4NNer

Projeto desenvolvido para a disciplina de Computação Gráfica e Realidade Virtual.

O objetivo do projeto é desenvolver uma aplicação web capaz de capturar
múltiplas imagens de um objeto e gerar uma representação tridimensional
utilizando técnicas de fotogrametria.

## Tecnologias previstas

### Backend
- Python
- FastAPI
- SQLite

### Processamento
- OpenCV
- COLMAP
- Open3D

### Frontend
- React
- Three.js

## Ambiente

- Windows
- WSL2
- Ubuntu
- NVIDIA GTX 1650

## Status

Projeto em desenvolvimento.
